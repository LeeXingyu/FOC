## 一、状态机控制（State Machine）

| 索引 | 子索引 | 名称 | 类型 | 访问 | 说明 |
|------|--------|------|------|------|------|
| **0x6040** | 0x00 | **Controlword** | UINT16 | rw | 控制字：状态机切换、使能、急停、故障复位 |
| **0x6041** | 0x00 | **Statusword** | UINT16 | ro | 状态字：当前状态、故障、到位标志 |

### Controlword 位定义
| 位 | 符号 | 名称 | 说明 |
|----|------|------|------|
| 0 | SO | Switch on | 请求进入 Switched On |
| 1 | EV | Enable Voltage | 主电源接通 |
| 2 | QS | Quick Stop | 0 = 请求快速停止 |
| 3 | EO | Enable Operation | 请求进入 Operation Enabled |
| 4 |  | Operation mode specific | PP: New set-point / HM: Start homing / IP: Enable interpolation |
| 5 |  | Operation mode specific | PP: Change set immediately / IP: Enable interpolation |
| 6 |  | Operation mode specific | PP: 0=绝对位置, 1=相对位置 / IP: 保留 |
| 7 | FR | Fault Reset | 上升沿复位故障 |
| 8 | HALT | Halt | 1 = 暂停当前运动 |
| 9 |  | Operation mode specific | PP: 保留 |
| 10 |  | Reserved | — |
| 11 |  | Manufacturer specific | — |
| 12-15 |  | Manufacturer specific | — |

### Statusword 位定义
| 位 | 符号 | 名称 | 说明 |
|----|------|------|------|
| 0 | RTSO | Ready to switch on | — |
| 1 | SO | Switched on | — |
| 2 | OE | Operation enabled | 电机已使能 |
| 3 | F | Fault | 故障 |
| 4 | VE | Voltage enabled | 主电压已接入 |
| 5 | QS | Quick stop | 0 = 快速停止中 |
| 6 | SOD | Switch on disabled | 初始状态 |
| 7 | W | Warning | 警告 |
| 8 |  | Manufacturer specific | — |
| 9 | REM | Remote | 远程控制中 |
| 10 | TAR | Target reached | 目标到达 |
| 11 | ILA | Internal limit active | 内部限位触发 |
| 12 |  | Operation mode specific | PP: Set-point acknowledge / HM: Homing attained |
| 13 |  | Operation mode specific | PP: Following error / HM: Homing error |
| 14-15 |  | Manufacturer specific | — |

### 状态机切换指令
| 状态转换 | Controlword 值 | 说明 |
|----------|---------------|------|
| Shutdown | 0x0006 | Switch On Disabled → Ready to Switch On |
| Switch On | 0x0007 | Ready to Switch On → Switched On |
| Enable Operation | 0x000F | Switched On → Operation Enabled |
| Disable Voltage | 0x0000 | 任何状态 → Switch On Disabled |
| Quick Stop | 0x0002 | Operation Enabled → Quick Stop Active |
| Disable Operation | 0x0007 | Operation Enabled → Switched On |
| Fault Reset | 0x0080 | Fault → Switch On Disabled（上升沿） |

## 八、单位换算与齿轮比

| 索引 | 子索引 | 名称 | 类型 | 访问 | 说明 |
|------|--------|------|------|------|------|
| **0x608F** | 0x01/02 | **Position Encoder Resolution** | UINT32 | rw | 编码器分辨率(分子/分母) |
| 0x6090 | 0x01/02 | Velocity Encoder Resolution | UINT32 | rw | 速度编码器分辨率 |
| **0x6091** | 0x01/02 | **Gear Ratio** | UINT32 | rw | 齿轮比(电机转数/轴转数) |
| 0x6092 | 0x01/02 | Feed Constant | UINT32 | rw | 导程常数(每转位移) |
| 0x6093 | 0x01/02 | Position Factor | UINT32 | rw | 位置换算因子 |
| 0x6094 | 0x01/02 | Velocity Factor | UINT32 | rw | 速度换算因子 |
| 0x6095 | 0x01/02 | Acceleration Factor | UINT32 | rw | 加速度换算因子 |

### 换算关系
```
实际位置[单位] = Position Actual Value × (Position Factor分子 / Position Factor分母)
实际速度[单位] = Velocity Actual Value × (Velocity Factor分子 / Velocity Factor分母)
```

## 十一、FOC 三环控制与 CiA 402 映射

```
┌─────────────────────────────────────────────────────────────┐
│                    CiA 402 对象字典                          │
├─────────────────────────────────────────────────────────────┤
│  0x607A Target Position   ──→  位置环给定 (Position Loop)   │
│  0x60FF Target Velocity   ──→  速度环给定 (Speed Loop)       │
│  0x6071 Target Torque     ──→  电流环 Iq* 给定 (FOC核心)    │
├─────────────────────────────────────────────────────────────┤
│  0x6064 Position Actual   ←──  编码器位置 (Encoder)         │
│  0x606C Velocity Actual   ←──  编码器微分/观测器             │
│  0x6078 Current Actual    ←──  FOC 采样 Iq                  │
│  0x6077 Torque Actual     ←──  Iq × Kt (转矩常数)           │
└─────────────────────────────────────────────────────────────┘
```
